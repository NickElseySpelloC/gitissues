Getting Started

Signing In

GitIssues uses GitHub's secure OAuth device flow to authenticate. No password is stored by the app.

  1. Launch GitIssues. The sign-in screen appears on first launch.
  2. Click Sign In with GitHub. A one-time code is displayed and your browser opens to GitHub's device activation page.
  3. Enter the code on the GitHub page and click Authorize.
  4. Return to GitIssues. The app detects authorisation automatically and loads your issues.
Tip Your access token is stored securely in the macOS Keychain. You only need to sign in once.

Private Repository Access

By default, GitIssues requests access to your public repositories only. To include private repositories, go to Settings and enable Allow private repository access. You will be asked to re-authenticate with GitHub to grant the broader permission.

The Main Window

The GitIssues window is divided into two panels:

  • Left — Issue List: All your issues, with search, filters, and sort controls at the top. You can drag the divider to resize this panel; the width is remembered between sessions.
  • Right — Detail Panel: Shows the full details of the selected issue, including its description, labels, assignees, and comments. When multiple issues are selected, this panel shows batch action controls instead.

Toolbar

The toolbar at the top right of the window contains three buttons:

ButtonAction
+ (New Issue)Opens the Create Issue window
↺ (Refresh)Fetches the latest issues from GitHub. Shows a spinner while refreshing.
Sign OutSigns you out and returns to the sign-in screen

Signing Out

Click Sign Out in the toolbar. Your issues and filter preferences are cleared. Your GitHub authorisation remains active; to fully revoke access, visit github.com › Settings › Applications › Authorized OAuth Apps.
