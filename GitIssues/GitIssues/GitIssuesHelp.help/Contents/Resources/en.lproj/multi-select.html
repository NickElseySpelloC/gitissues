Batch Operations

GitIssues lets you select multiple issues at once and perform actions on all of them in a single step.

Selecting Multiple Issues

ActionResult
⌘ clickAdd or remove an individual issue from the selection
⇧ clickSelect a contiguous range of issues
Click elsewhereClears the selection

When two or more issues are selected, the detail panel on the right switches to batch mode.

The Batch Panel

The batch panel shows:

  • The count of selected issues (e.g. 5 Issues Selected)
  • A preview list of up to five issue titles with their state icons. If more than five are selected, a note shows how many additional issues are included.
  • Action buttons for the available batch operations

Available Batch Operations

Clone Issues

Creates a copy of each selected issue. Each clone gets the original title with " copy" appended, the same body, and the same labels. Clones are created as new open issues in the same repository.

A confirmation dialog shows the count before cloning begins.

Assign Issues

Opens the Assign sheet so you can choose assignees to apply to all selected issues at once. The chosen assignees replace the existing assignees on every selected issue.

Close Open Issues

Closes all open issues in the selection. Issues that are already closed are skipped. The button label shows exactly how many open issues will be affected (e.g. Close 3 Open Issues). This button does not appear if none of the selected issues are open.

A confirmation dialog appears before any issues are closed.

Delete Issues

Permanently deletes all selected issues from GitHub. A confirmation dialog shows the count before deletion begins.

Important Batch deletion permanently removes all selected issues from GitHub. This cannot be undone.

Using the Context Menu for Batch Operations

You can also trigger batch operations from the context menu. With multiple issues selected, right-click on any selected issue to see the batch menu instead of the single-issue menu. Right-clicking on an unselected issue shows the standard single-issue menu for that issue only.

Tip All batch operations show a confirmation dialog before doing anything, so you can review the count and cancel if needed.
