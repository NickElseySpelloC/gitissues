Editing Issues

To edit an issue, do any of the following:

  • Select the issue in the list and press Return.
  • Click the Edit button in the detail panel header.
  • Right-click the issue in the list and choose Edit Issue.

The Edit Issue window opens, pre-populated with the current values.

Editable Fields

Title

Update the issue title. A title is required — the form cannot be saved without one.

Description

Edit the issue body using the Markdown editor. The editor supports the same formatting options as when creating an issue.

State

Toggle between Open and Closed using the state selector. This is the equivalent of closing or reopening an issue on GitHub.

Tip You can also close or reopen an issue directly from the context menu in the issue list, without opening the Edit window.

Labels

Click labels to add or remove them. Changes are applied when you save.

What Cannot Be Changed

  • Repository — an issue cannot be moved to a different repository from within GitIssues.
  • Author — the original author is set at creation and cannot be changed.
  • Comments — edit comments separately from the detail panel.

Saving Changes

Click Save Changes to apply your edits. Only fields that have actually changed are sent to GitHub, so the operation is efficient. The issue list and detail panel update immediately on save.

Click Cancel to discard your changes and close the window.

Cloning an Issue

Right-click an issue and choose Clone Issue to create a copy. The cloned issue gets the same title (with " copy" appended), the same body, and the same labels. It is created as a new open issue in the same repository.
