Before You Contact Support

It can help to have the following information ready:

  • Your macOS version (Apple menu › About This Mac)
  • The version of GitIssues you are running (GitIssues menu › About GitIssues)
  • A description of what you were doing when the problem occurred
  • Any error messages that appeared

Common Questions

Issues are not loading

Check your internet connection, then click the ↺ Refresh button in the toolbar. If the problem persists, try signing out and signing back in.

I can't see my private repositories

Go to Settings and enable Allow private repository access, then re-authenticate with GitHub.

A label or assignee change isn't showing up

Click the ↺ Refresh button to fetch the latest data from GitHub. If background sync is enabled, the list will update automatically within the configured interval.

I accidentally deleted an issue

Unfortunately, issue deletion is permanent and cannot be reversed within GitIssues. GitHub's own support may be able to assist in exceptional cases — visit support.github.com.
