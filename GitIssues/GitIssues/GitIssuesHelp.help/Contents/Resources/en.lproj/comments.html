Comments

Comments appear in the detail panel below the issue description. The section heading shows a count, e.g. Comments (4).

Adding a Comment

  1. Select an issue to open it in the detail panel.
  2. Scroll to the bottom and click Add Comment. A new window opens.
  3. Type your comment in the Markdown editor.
  4. Click Add Comment to post it, or press ⌘Return.

Save and Close Issue

If the issue is currently open, the comment window also shows a Save and Close Issue button. Clicking it posts your comment and simultaneously closes the issue — useful for leaving a resolution note as you close.

Editing a Comment

  1. Find the comment in the detail panel.
  2. Click the pencil icon on the right of the comment.
  3. The Edit Comment window opens, pre-populated with the existing text.
  4. Make your changes and click Save Changes, or press ⌘Return.

Deleting a Comment

  1. Click the trash icon on the right of the comment.
  2. The comment is removed immediately from the detail panel.
Important Comment deletion is immediate and cannot be undone. The change is reflected on GitHub straight away.

Markdown in Comments

The comment editor supports the full range of GitHub-flavoured Markdown. Use the editor toolbar for quick access to formatting buttons, or switch to preview mode to see how your comment will look before posting.

Tip You can use Escape to cancel and close the comment window without saving.
