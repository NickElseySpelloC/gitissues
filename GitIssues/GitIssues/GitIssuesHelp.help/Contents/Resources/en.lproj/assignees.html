Assignees

Assignees are the GitHub collaborators responsible for working on an issue. You can assign one or more people to any issue directly from GitIssues.

Viewing Assignees

Current assignees are listed in the Assignees section of the detail panel, below the labels. If no one is assigned, this section is hidden.

Assigning an Issue

To add or change assignees for a single issue:

  1. Open the issue in the detail panel.
  2. Click the Assign button (person icon) in the header, or right-click the issue in the list and choose Assign Issue.
  3. The Assign sheet opens, showing all collaborators for that repository.
  4. Click a collaborator's name to select or deselect them. Currently assigned people are shown pre-selected.
  5. Use the search field at the top to filter collaborators by name.
  6. Click Assign (or press ⌘Return) to save.
Tip You can select multiple assignees. Click Cancel or press Escape to close the sheet without making changes.

Removing All Assignees

Open the Assign sheet, deselect all currently selected collaborators, and click Assign. The issue will be left unassigned.

Assigning Multiple Issues at Once

You can assign the same set of people to several issues in one step using batch operations:

  1. Select multiple issues in the list using ⌘ click.
  2. Click Assign N Issues in the detail panel, or right-click a selected issue and choose Assign N Issues.
  3. Choose assignees in the sheet that appears.
  4. Click Assign. The chosen assignees are applied to all selected issues.
Note When assigning multiple issues, the sheet does not pre-select any assignees, since the selected issues may have different current assignees. Any selection you make replaces the existing assignees on all selected issues.
